# Mac Home View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A "Home" pane in the Mac main window (fifth sidebar tab, Ctrl-Cmd-5) that shows connection and dashboard/profile, what needs the user and what is running, recent chats, a few metrics the client already has (sessions, unread, model, context, activity per day, Kanban counts, cron), and New Chat / Quick Ask / Kanban actions.

**Architecture:** All metric computation is a pure, Foundation-only `MacHomeSnapshot.make(_:calendar:)` over plain `MacHomeInput` values (reusable by the D25 widgets). A `@MainActor MacHomeModel` with injected `Sources` throttles AppState/feed changes into snapshots and runs a refresh/poll loop only while the view is mounted. `MacHomeBinding` maps `AppState`, `AgentActivityFeed.shared` and a Home-owned `KanbanService` fetch into `MacHomeInput`. `MacHomeView` is built from small components and mounted by `MacDetailRouter` for a new `.home` destination. The only upstream edit is the `SidebarTab.home` case in `Conduit/Views/SidebarTab.swift` (three gated regions).

**Tech Stack:** Swift 5.9 language mode / SwiftUI / AppKit / Combine on macOS 14+, XCTest. xcodegen project (`project.yml`), scheme `ConduitMac`.

**Spec:** `docs/superpowers/specs/2026-10-16-mac-home-design.md` (its open questions are resolved to the defaults it states; see "Resolved Decisions").

Never run two xcodebuilds on one checkout. Known flaky: `LiquidOrbViewMacTests.testHiddenWindowStopsTheMeterAndShowingResumesIt`.
- zsh: quote every glob and every path containing `*`, `[`, `?`.
- TDD: failing test, run to see it fail, minimal implementation, run to see it pass, commit.
- Tests: injected `UserDefaults` suites (`HostedTestSupport.makeSuite`/`dropSuite`), polling waits (`HostedTestSupport.waitUntil`, `settle`), explicit teardown, no fixed sleeps for positive assertions. Never touch the live app's defaults. The user's own Conduit may be running: do not quit, click or type into it.
- Localization (docs/LOCALIZATION.md): every user-visible string is `AppLocalization.string("...")` (or a SwiftUI literal for `Text`/`Button` titles) with an English source key. No string embeds a count with a singular noun: tiles show a number over a label; formats use `%lld` with a label word ("Today %lld"). Task 7 adds the keys for every shipped language through `scripts/l10n.py`.
- Untrusted text: every gateway- or agent-controlled string (session titles, models, live-row title and detail, Kanban column names, cron job names, dashboard label) goes through `MacUntrustedText.sanitize(_:maxGraphemes:)` inside `MacHomeSnapshot.make`, and views draw it with `Text(verbatim:)`. Limits: title 80, detail 120, label/model 40, cron name 60, Kanban column 24.
- Surface style: cards use `conduitGlassSurface(cornerRadius: 12)` (`MacSidebarMetrics.sessionCardRadius`), the only glass layer (D7); controls are `MacControlHeight.compact` (32 pt) with `conduitGlassControl`; header is `MacPaneHeader`; no new `Form` (D14 not needed). Secondary text is `Color.primary` at 0.7 opacity (system `.secondary` is below 4.5:1, see `MacPaletteContrastTests`); non-text chart marks reach 3:1 against the window background in light and dark.
- Data limits: recent chats 8; chart days 7; Kanban refresh every 60 s while the app is active; snapshot tick every 30 s; AppState change throttle 0.5 s; context "high" at 85 percent (Home's own threshold).
- Persistence: none new. The route uses the existing `conduit.sidebarTab` key; Kanban board choice is read (never written) from `KanbanStore.scopedBoardKey(serverIdentity:)`.

## Resolved Decisions (spec open questions, spec defaults)

1. Launch default stays Sessions; no `MacDefaults` change.
2. Tab strip uses a three-step ladder (five names; four names + compact Home icon; all icons). Task 6 measures it at 340 pt; if the second step does not fit, the shipped behaviour is all icons and D24 records the measured widths.
3. Home is the last tab; shortcut Ctrl-Cmd-5 (Go > Home).
4. Cron load failures surface through the existing `errorMessage` path (`loadCronJobs()`).
5. Live data comes from `AgentActivityFeed.shared` (D16 visibility limits apply and are stated in the UI).
6. Recent chats: 8, excluding cron runs and archived sessions.
7. Kanban: the board last selected for this server, else the server's current board (one retry with the current board if the saved slug fails).
8. No hide/reorder of sections in v1; no inline approve/deny.

## Review Focus

1. Titles, tool names, approval commands and column names carrying a bidi override (U+202E), a newline, zero-width characters, or 10,000 characters: sanitized, one line, no layout blow-up. Tests in Task 1 (snapshot) and Task 4 (view at 430 pt).
2. Dashboard or profile switch while Home is open: Kanban and cron must not show the old scope's data, and a Kanban response that lands after the switch or after leaving Home must be dropped. Tests in Task 2 (reset drops a late response) and Task 3 (appearing resets Kanban and cron before anything is fetched).
3. Disconnected, reconnecting, feed `.eventsOnly`, feed not yet baselined, zero sessions, no cron jobs, empty board: each has a stated state and none shows a misleading "Nothing running". Tests in Tasks 1 and 4.
4. A catalog of 5000 sessions: bounded work, at most 8 recent rows, 7 chart columns. Test in Task 1.
5. The clock crossing midnight with Home open and no data change: "today" moves. Test in Task 3 (injected clock).
6. The default 340 pt sidebar column and a 430 pt detail column: the strip still shows the four existing names (or falls back to icons deliberately) and the tile grid does not clip. Tests in Tasks 4 and 6.

```swift
    /// A fixed Gregorian calendar in UTC, so day buckets do not depend on the machine's zone.
    static var utc: Calendar {
        var calendar = Calendar(identifier: .gregorian)
        calendar.timeZone = TimeZone(identifier: "UTC")!
        return calendar
    }

    static func date(_ iso: String) -> Date {
        ISO8601DateFormatter().date(from: iso)!
```

```swift
import XCTest

final class MacHomeSnapshotTests: XCTestCase {
    private let calendar = MacHomeTestCalendar.utc
    private let now = MacHomeInput.referenceNow

    private func make(_ input: MacHomeInput) -> MacHomeSnapshot {
        MacHomeSnapshot.make(input, calendar: calendar)
    }

    // MARK: Live rows

    func testLiveDedupesPerSessionAndNeedsUserWins() {
        let working = MacHomeLiveItem.fixture("turn:1", session: "s1", kind: .turn, since: now.addingTimeInterval(-600))
        let approval = MacHomeLiveItem.fixture("approval:9", session: "s1", kind: .approval, needsUser: true, since: now.addingTimeInterval(-60))
        let other = MacHomeLiveItem.fixture("turn:2", session: "s2", kind: .turn, since: now.addingTimeInterval(-30))
        let snap = make(.fixture(live: [working, approval, other]))
        XCTAssertEqual(snap.needsYou.map(\.id), ["approval:9"])
        XCTAssertEqual(snap.working.map(\.id), ["turn:2"])
    }

    func testLiveRowsAreOldestFirst() {
        let a = MacHomeLiveItem.fixture("a", session: "a", since: now.addingTimeInterval(-10))
        let b = MacHomeLiveItem.fixture("b", session: "b", since: now.addingTimeInterval(-500))
        let c = MacHomeLiveItem.fixture("c", session: "c", since: now.addingTimeInterval(-500))

    }

        XCTAssertTrue(snap.working.isEmpty)
```

```swift
    private static func liveRows(_ items: [MacHomeLiveItem]) -> [MacHomeLiveRow] {
        var best: [String: MacHomeLiveItem] = [:]
        var order: [String] = []
        for item in items {
            let key = item.sessionKey ?? item.id
            guard let current = best[key] else {
                best[key] = item
                order.append(key)
                continue
            }
            if prefers(item, over: current) { best[key] = item }
        }
        return order.compactMap { best[$0] }
            .sorted { $0.since != $1.since ? $0.since < $1.since : $0.id < $1.id }
            .map { item in
                let detail = item.detail.map { clean($0, Limit.detail) }
                return MacHomeLiveRow(
                    id: item.id, openID: item.openID, kind: item.kind, needsUser: item.needsUser,
                    title: clean(item.title, Limit.title),
                    detail: (detail?.isEmpty ?? true) ? nil : detail,
                    since: item.since
                )
            }
    }

    /// A needs-you item replaces a working one for the same session; otherwise the older wins.
    private static func prefers(_ a: MacHomeLiveItem, over b: MacHomeLiveItem) -> Bool {
        if a.needsUser != b.needsUser { return a.needsUser }
        if a.since != b.since { return a.since < b.since }
        return a.id < b.id
    }

    private static func recent(_ sessions: [MacHomeSession]) -> [MacHomeRecentRow] {
        let ordered = sessions.sorted { a, b in
            switch (a.lastActivity, b.lastActivity) {
            case let (x?, y?): return x != y ? x > y : a.id < b.id
            case (_?, nil): return true
            case (nil, _?): return false
            case (nil, nil): return a.id < b.id
            }
        }
        return ordered.prefix(recentLimit).map {
            MacHomeRecentRow(
                id: $0.id, title: clean($0.title, Limit.title), model: clean($0.model, Limit.label),
                lastActivity: $0.lastActivity, isUnread: $0.isUnread
            )
        }

    private static func dayBuckets(_ sessions: [MacHomeSession], now: Date, calendar: Calendar) -> [MacHomeDay] {
        let today = calendar.startOfDay(for: now)
        var starts: [Date] = []
        for offset in stride(from: dayCount - 1, through: 0, by: -1) {
            let shifted = calendar.date(byAdding: .day, value: -offset, to: today) ?? today
            starts.append(calendar.startOfDay(for: shifted))
        }
        let window = Set(starts)
        var counts: [Date: Int] = [:]
        for session in sessions {
            guard let time = session.lastActivity else { continue }
            let key = calendar.startOfDay(for: time)
            if window.contains(key) { counts[key, default: 0] += 1 }
        }
        return starts.map { MacHomeDay(start: $0, count: counts[$0] ?? 0, isToday: $0 == today) }
    }

    private static func cron(_ jobs: [MacHomeCronJob]?, now: Date) -> MacHomeCronSummary? {
        guard let jobs else { return nil }
        let active = jobs.filter(\.isActive)
        let upcoming = active
            .compactMap { job in job.nextRun.map { (job: job, date: $0) } }
            .filter { $0.date >= now }
            .min { $0.date != $1.date ? $0.date < $1.date : $0.job.id < $1.job.id }
        return MacHomeCronSummary(
            active: active.count,
            paused: jobs.count - active.count,
            failing: jobs.filter(\.hasError).count,
            next: upcoming.map { MacHomeCronNext(name: clean($0.job.name, Limit.cronName), date: $0.date) }
        )
    }

    private static func kanban(_ input: MacHomeKanbanInput) -> MacHomeKanbanSummary {
        switch input {
        case .notLoaded:
            return MacHomeKanbanSummary(state: .notLoaded, bars: [], total: 0, blocked: 0)
        case .unavailable:
            return MacHomeKanbanSummary(state: .unavailable, bars: [], total: 0, blocked: 0)
        case .loaded(let columns):
            let shown = columns
                .filter { $0.status != "archived" }
                .sorted {
                    $0.sortOrder != $1.sortOrder
                        ? $0.sortOrder < $1.sortOrder
                        : $0.displayName.localizedCaseInsensitiveCompare($1.displayName) == .orderedAscending
                }
            let peak = max(shown.map { max($0.count, 0) }.max() ?? 0, 1)
            let bars = shown.map { column -> MacHomeKanbanBar in
                let count = max(column.count, 0)
                let name = clean(column.displayName, Limit.column)
                return MacHomeKanbanBar(
                    id: column.status,
                    name: name.isEmpty ? clean(column.status, Limit.column) : name,
                    count: count,
                    fraction: Double(count) / Double(peak)
                )
            }
            let total = bars.reduce(0) { $0 + $1.count }
            return MacHomeKanbanSummary(
                state: total == 0 ? .empty : .loaded,
                bars: bars,
                total: total,
                blocked: bars.first { $0.id == "blocked" }?.count ?? 0
            )
        }
    }

    private static func context(_ runtime: MacHomeRuntime) -> MacHomeContext? {
        guard runtime.contextMax > 0 || runtime.contextPercent > 0 else { return nil }
        let raw = runtime.contextPercent.isFinite ? runtime.contextPercent : 0
        let percent = min(max(raw, 0), 100)
        return MacHomeContext(
            percent: percent,
            used: max(runtime.contextUsed, 0),
            max: max(runtime.contextMax, 0),
            isHigh: percent >= highContextPercent
        )
    }

    private static func modelLine(_ runtime: MacHomeRuntime) -> MacHomeModelLine? {
        let model = clean(runtime.model, Limit.label)
        guard !model.isEmpty else { return nil }
        return MacHomeModelLine(
            model: model,
            provider: clean(runtime.provider, Limit.label),
            effort: clean(runtime.reasoningEffort, Limit.label)
        )
    }

enum MacHomeDates {
    /// `CronJob.nextRunAt` is a raw String and no fixture pins its format.
    /// Accepts ISO 8601 with a zone, with or without fractional seconds; a
    /// zone-less value is read as the Mac's local time. Anything else is nil.
    static func parse(_ raw: String?) -> Date? {
        guard let text = raw?.trimmingCharacters(in: .whitespacesAndNewlines), !text.isEmpty else { return nil }
        let fractional = ISO8601DateFormatter()
        fractional.formatOptions = [.withInternetDateTime, .withFractionalSeconds]
        if let date = fractional.date(from: text) { return date }
        let plain = ISO8601DateFormatter()
        plain.formatOptions = [.withInternetDateTime]
        if let date = plain.date(from: text) { return date }
        let local = DateFormatter()
        local.locale = Locale(identifier: "en_US_POSIX")
        local.timeZone = .current
        local.dateFormat = "yyyy-MM-dd'T'HH:mm:ss"
        return local.date(from: text)
    }
```

```swift
import Foundation

/// Task counts per Kanban column for Home (D24). Home does not own a
/// `KanbanStore` (that is private to `KanbanView`); the live `Fetch` is built
/// in `MacHomeBinding` over `KanbanService`. A generation counter makes a late
/// response from a previous scope (reset, newer load) inert.
@MainActor
final class MacHomeKanbanLoader: ObservableObject {
    typealias Fetch = @MainActor (_ slug: String?) async throws -> [MacHomeKanbanColumnInput]

    @Published private(set) var state: MacHomeKanbanInput = .notLoaded

    private let fetch: Fetch
    private var generation = 0

    init(fetch: @escaping Fetch) {
        self.fetch = fetch
    }

    /// A new dashboard or profile: forget everything, drop any response still in flight.
    func reset() {
        generation += 1
        state = .notLoaded
    }

    /// No dashboard bridge (or another reason Kanban cannot be asked).
    func markUnavailable() {
        generation += 1
        state = .unavailable
    }

    /// `preferredSlug` is the board the user last selected for this server;
    /// nil or empty asks for the server's current board.
    func load(preferredSlug: String?) async {
        generation += 1
        let mine = generation
        do {
            let columns = try await fetchWithFallback(preferredSlug)
            guard mine == generation else { return }
            state = .loaded(columns)
        } catch {
            if error is CancellationError || Task.isCancelled { return }
            guard mine == generation else { return }
            // A transient failure keeps the last board on screen.
            if case .loaded = state { return }
            state = .unavailable
        }
    }

    private func fetchWithFallback(_ slug: String?) async throws -> [MacHomeKanbanColumnInput] {
        guard let slug, !slug.isEmpty else { return try await fetch(nil) }
        do {
            return try await fetch(slug)
        } catch {
            if error is CancellationError || Task.isCancelled { throw error }
            // The saved board may have been deleted: one retry on the current board.
            return try await fetch(nil)
        }
    }
}
```

```swift
import Combine
import Foundation

enum MacHomeRefreshReason: Equatable {
    /// The pane appeared, or the connection scope changed.
    case appeared
    /// The poll loop; skipped by the live binding while the app is inactive.
    case periodic
}

/// Turns changes in AppState, the activity feed and the Kanban loader into
/// `MacHomeSnapshot`s for the Home view (D24). Owned by the view, so its
/// subscriptions and polls exist only while Home is the shown pane.
@MainActor
final class MacHomeModel: ObservableObject {
    struct Sources {
        var input: @MainActor (_ now: Date) -> MacHomeInput
        /// Fires (before the change lands) whenever anything Home reads may have changed.
        var changes: AnyPublisher<Void, Never>
        var refresh: @MainActor (_ reason: MacHomeRefreshReason) async -> Void
    }

    @Published private(set) var snapshot: MacHomeSnapshot

    private let sources: Sources
    private let calendar: Calendar
    private let clock: () -> Date
    private let tick: Duration
    private let refreshEvery: Int
    private var changeSubscription: AnyCancellable?

    init(
        sources: Sources,
        calendar: Calendar = .current,
        clock: @escaping () -> Date = Date.init,
        throttle: TimeInterval = 0.5,
        tick: Duration = .seconds(30),
        refreshEvery: Int = 2
    ) {
        self.sources = sources
        self.calendar = calendar
        self.clock = clock
        self.tick = tick
        self.refreshEvery = max(refreshEvery, 1)
        self.snapshot = MacHomeSnapshot.make(sources.input(clock()), calendar: calendar)
        // `objectWillChange` fires before the value lands, so hop to the next
        // run-loop turn first; then coalesce bursts (a streaming turn).
        changeSubscription = sources.changes
            .receive(on: RunLoop.main)
            .throttle(for: .seconds(throttle), scheduler: RunLoop.main, latest: true)
            .sink { [weak self] in
                MainActor.assumeIsolated { self?.rebuild() }
            }
    }

    /// Publishes only when the snapshot differs: AppState publishes constantly.
    func rebuild() {
        let next = MacHomeSnapshot.make(sources.input(clock()), calendar: calendar)
        if next != snapshot { snapshot = next }
    }

    /// The view's `.task(id: scope)`: refresh once, then tick (day rollover, relative
    /// times) and refresh every `refreshEvery` ticks until cancelled.
    func run() async {
        rebuild()
        await sources.refresh(.appeared)
        rebuild()
        var ticks = 0
        while !Task.isCancelled {
            do { try await Task.sleep(for: tick) } catch { return }
            rebuild()
            ticks += 1
            if ticks % refreshEvery == 0 {
                await sources.refresh(.periodic)
                if Task.isCancelled { return }
                rebuild()
            }
        }
    }
}
```

```swift
enum MacHomeKanbanError: Error { case noDashboard }

/// Maps AppState, the activity feed and the Kanban loader into `MacHomeInput`.
@MainActor
enum MacHomeBinding {
    /// Whether this Home session has asked for the cron list yet. A reference box
    /// because `Sources` closures share it.
    final class CronLoadState { var loaded = false }

    static func makeModel(appState: AppState) -> MacHomeModel {
        MacHomeModel(sources: sources(appState: appState, feed: AgentActivityFeed.shared, kanban: makeKanbanLoader(appState: appState)))
    }

    static func makeKanbanLoader(appState: AppState) -> MacHomeKanbanLoader {
        MacHomeKanbanLoader { [weak appState] slug in
            guard let bridge = appState?.dashboardTicketBridge else { throw MacHomeKanbanError.noDashboard }
            let board = try await KanbanService(requester: bridge).fetchBoard(slug: slug, includeArchived: false)
            return board.columns.map { column in
                let presentation = KanbanStatusPresentation.forStatus(column.name)
                return MacHomeKanbanColumnInput(
                    status: column.name, displayName: presentation.displayName,
                    sortOrder: presentation.sortOrder, count: column.tasks.count
                )
            }
        }
    }

    static func sources(
        appState: AppState,
        feed: AgentActivityFeed?,
        kanban: MacHomeKanbanLoader,
        defaults: UserDefaults = .standard
    ) -> MacHomeModel.Sources {
        let cron = CronLoadState()
        var publishers: [AnyPublisher<Void, Never>] = [
            appState.objectWillChange.eraseToAnyPublisher(),
            kanban.objectWillChange.eraseToAnyPublisher(),
        ]
        if let feed { publishers.append(feed.objectWillChange.eraseToAnyPublisher()) }
        return MacHomeModel.Sources(
            input: { now in
                input(appState: appState, feed: feed, kanban: kanban.state, cronLoaded: cron.loaded, now: now)
            },
            changes: Publishers.MergeMany(publishers).eraseToAnyPublisher(),
            refresh: { reason in
                await refresh(reason, appState: appState, feed: feed, kanban: kanban, cron: cron, defaults: defaults)
            }
        )
    }

    // MARK: Refresh

    static func refresh(
        _ reason: MacHomeRefreshReason,
        appState: AppState,
        feed: AgentActivityFeed?,
        kanban: MacHomeKanbanLoader,
        cron: CronLoadState,
        defaults: UserDefaults
    ) async {
        // The poll loop is for a Home someone is looking at.
        if reason == .periodic, !NSApplication.shared.isActive { return }
        if reason == .appeared {
            // A new scope (or first appearance): never show the old dashboard's data.
            kanban.reset()
            cron.loaded = false
        }
        feed?.refreshNow()
        guard appState.isConnected else { return }
        // Failures surface through the shared errorMessage path, like the Cron pane (spec open question 4).
        await appState.loadCronJobs()
        cron.loaded = true
        guard let bridge = appState.dashboardTicketBridge else {
            kanban.markUnavailable()
            return
        }
        // The board the user last picked for this server (KanbanStore writes it; Home only reads).
        let saved = defaults.string(forKey: KanbanStore.scopedBoardKey(serverIdentity: bridge.baseURL))
        await kanban.load(preferredSlug: saved)
    }

    // MARK: Input

    static func input(
        appState: AppState,
        feed: AgentActivityFeed?,
        kanban: MacHomeKanbanInput,
        cronLoaded: Bool,
        now: Date
    ) -> MacHomeInput {
        let state: MacHomeConnectionState = appState.isConnected ? .connected : (appState.isConnecting ? .connecting : .offline)
        let sessions = appState.activeProfileSessions
            .filter { !$0.isArchived }
            .map { session in
                MacHomeSession(
                    id: session.id, title: session.title, model: session.model,
                    lastActivity: session.lastActivityAt.map { Date(timeIntervalSince1970: $0) },
                    isUnread: appState.isSessionUnread(session)
                )
            }
        let runtime = appState.runtime
        return MacHomeInput(
            now: now,
            scope: "\(appState.activeDashboardID?.uuidString ?? "none")|\(appState.activeProfile)|\(appState.isConnected)",
            connection: MacHomeConnection(
                state: state,
                dashboardLabel: appState.savedDashboardRegistry.activeDashboardLabel,
                profileName: appState.profileDisplayName(appState.activeProfile)
            ),
            sessions: sessions,
            live: feed.map { liveItems($0.items) } ?? [],
            feed: availability(feed),
            cron: cronLoaded ? cronJobs(appState.cronJobs) : nil,
            kanban: kanban,
            runtime: MacHomeRuntime(
                model: runtime.model, provider: runtime.provider, reasoningEffort: runtime.reasoningEffort,
                contextPercent: runtime.contextPercent, contextUsed: runtime.contextUsed, contextMax: runtime.contextMax
            ),
            subAgents: appState.activeAgents,
            canStartChat: !appState.macNewChatDisabled
        )
    }

    private static func availability(_ feed: AgentActivityFeed?) -> MacHomeFeedAvailability {
        guard let feed else { return .offline }
        switch feed.availability {
        case .offline: return .offline
        case .eventsOnly: return .eventsOnly
        case .live: return feed.isBaselined ? .live : .loading
        }
    }

    /// Unfinished turns and decisions only; Kanban and cron feed rows are the notch plan's.
    static func liveItems(_ items: [AgentActivityItem]) -> [MacHomeLiveItem] {
        items.compactMap { item in
            let kind: MacHomeLiveItem.Kind
            switch item.kind {
            case .turn: kind = .turn
            case .approval: kind = .approval
            case .clarify: kind = .clarify
            case .inputPrompt: kind = .inputPrompt
            case .kanban, .cron: return nil
            }
            let needsUser: Bool
            switch item.state {
            case .needsUser: needsUser = true
            case .working: needsUser = false
            case .blocked, .finished: return nil
            }
            return MacHomeLiveItem(
                id: item.id,
                sessionKey: item.sessionKey ?? item.sessionId,
                // The same id the notch opens (NotchStatusController.openSession(of:)).
                openID: item.sessionId ?? item.sessionKey,
                kind: kind, needsUser: needsUser,
                title: item.title, detail: item.detail, since: item.since
            )
        }
    }

    static func cronJobs(_ jobs: [CronJob]) -> [MacHomeCronJob] {
        jobs.map { job in
            MacHomeCronJob(
                id: job.id,
                name: job.displayName,
                isActive: job.isActive,
                hasError: !(job.lastError ?? "").trimmingCharacters(in: .whitespacesAndNewlines).isEmpty,
                nextRun: job.isFinished ? nil : MacHomeDates.parse(job.nextRunAt)
            )
        }
    }
}
```

```swift
/// Home's secondary text and chart marks against the window background in
/// light and dark, from the resolved colours (the method of MacPaletteContrastTests).
@MainActor
final class MacHomeContrastTests: XCTestCase {
    private struct RGBA { var r, g, b, a: Double }

    private func resolve(_ color: Color, dark: Bool) -> RGBA {
        var out = RGBA(r: 0, g: 0, b: 0, a: 1)
        NSAppearance(named: dark ? .darkAqua : .aqua)!.performAsCurrentDrawingAppearance {
            let c = NSColor(color).usingColorSpace(.sRGB) ?? .black
            out = RGBA(r: Double(c.redComponent), g: Double(c.greenComponent), b: Double(c.blueComponent), a: Double(c.alphaComponent))
        }
        return out
    }

    private func resolve(_ color: NSColor, dark: Bool) -> RGBA {
        var out = RGBA(r: 0, g: 0, b: 0, a: 1)
        NSAppearance(named: dark ? .darkAqua : .aqua)!.performAsCurrentDrawingAppearance {
            let c = color.usingColorSpace(.sRGB) ?? .black
            out = RGBA(r: Double(c.redComponent), g: Double(c.greenComponent), b: Double(c.blueComponent), a: Double(c.alphaComponent))
        }
        return out
    }

    private func over(_ fg: RGBA, _ bg: RGBA) -> RGBA {
        RGBA(r: fg.r * fg.a + bg.r * (1 - fg.a), g: fg.g * fg.a + bg.g * (1 - fg.a), b: fg.b * fg.a + bg.b * (1 - fg.a), a: 1)
    }

    private func luminance(_ c: RGBA) -> Double {
        func lin(_ v: Double) -> Double { v <= 0.03928 ? v / 12.92 : pow((v + 0.055) / 1.055, 2.4) }
        return 0.2126 * lin(c.r) + 0.7152 * lin(c.g) + 0.0722 * lin(c.b)
    }

    private func ratio(_ fg: RGBA, on background: RGBA) -> Double {
        let a = luminance(over(fg, background)), b = luminance(background)
        return (max(a, b) + 0.05) / (min(a, b) + 0.05)
    }

    func testSecondaryTextClearsFourPointFiveToOne() {
        for dark in [false, true] {
            let window = resolve(.windowBackgroundColor, dark: dark)
            XCTAssertGreaterThanOrEqual(ratio(resolve(MacHomeStyle.secondaryText, dark: dark), on: window), 4.5, dark ? "dark" : "light")
        }
    }

    func testChartMarksClearThreeToOne() {
        for dark in [false, true] {
            let window = resolve(.windowBackgroundColor, dark: dark)
            let name = dark ? "dark" : "light"
            XCTAssertGreaterThanOrEqual(ratio(resolve(MacHomeStyle.emphasisMark, dark: dark), on: window), 3, "emphasis mark, \(name)")
            XCTAssertGreaterThanOrEqual(ratio(resolve(MacHomeStyle.mutedMark, dark: dark), on: window), 3, "muted mark, \(name)")
        }
    }
}
```

```swift
/// Sessions touched per day, seven columns, today in the accent hue and the rest neutral
/// (the emphasis form). The accessibility label carries every value, which is also the table view.
struct MacHomeDayBars: View {
    let days: [MacHomeDay]
    var calendar: Calendar = .current

    static func summary(days: [MacHomeDay], calendar: Calendar = .current) -> String {
        days.map { day in
            let name = day.start.formatted(Date.FormatStyle(timeZone: calendar.timeZone).weekday(.abbreviated))
            return "\(name) \(day.count)"
        }.joined(separator: ", ")
    }

    var body: some View {
        let peak = max(days.map(\.count).max() ?? 0, 1)
        let plot = MacHomeStyle.chartHeight - 16
        VStack(spacing: 4) {
            HStack(alignment: .bottom, spacing: MacHomeStyle.barGap * 3) {
                ForEach(days) { day in
                    let barHeight: CGFloat = day.count == 0 ? 2 : max(4, plot * CGFloat(day.count) / CGFloat(peak))
                    VStack(spacing: 2) {
                        Text(verbatim: day.isToday ? "\(day.count)" : " ")
                            .font(.caption2.weight(.semibold)).monospacedDigit()
                            .foregroundStyle(MacHomeStyle.secondaryText)
                        Spacer(minLength: 0)
                        UnevenRoundedRectangle(
                            topLeadingRadius: MacHomeStyle.topCornerRadius, bottomLeadingRadius: 0,
                            bottomTrailingRadius: 0, topTrailingRadius: MacHomeStyle.topCornerRadius
                        )
                        .fill(day.isToday ? MacHomeStyle.emphasisMark : MacHomeStyle.mutedMark)
                        .frame(maxWidth: MacHomeStyle.maxBarThickness)
                        .frame(height: barHeight)
                    }
                    .frame(maxWidth: .infinity)
                    .contentShape(Rectangle())
                    .help(Text(verbatim: "\(day.start.formatted(Date.FormatStyle(timeZone: calendar.timeZone).weekday(.wide))): \(day.count)"))
                }
            }
            .frame(height: MacHomeStyle.chartHeight)
            HStack(spacing: MacHomeStyle.barGap * 3) {
                ForEach(days) { day in
                    Text(day.start.formatted(Date.FormatStyle(timeZone: calendar.timeZone).weekday(.narrow)))
                        .font(.caption2)
                        .foregroundStyle(MacHomeStyle.secondaryText)
                        .frame(maxWidth: .infinity)
                }
            }
        }
        .accessibilityElement(children: .ignore)
        .accessibilityLabel(Text(verbatim: AppLocalization.string("Sessions per day")))
        .accessibilityValue(Text(verbatim: Self.summary(days: days, calendar: calendar)))
    }
}

/// One ratio against a limit: a same-ramp track and fill, the number beside it, a warning
/// icon and words (never colour alone) from the high threshold.
struct MacHomeContextMeter: View {
    let context: MacHomeContext

    static func tokens(_ context: MacHomeContext) -> String {
        guard context.max > 0 else { return "" }
        let used = context.used.formatted(.number.notation(.compactName))
        let limit = context.max.formatted(.number.notation(.compactName))
        return String(format: AppLocalization.string("%@ of %@ tokens"), used, limit)
    }

    var body: some View {
        VStack(alignment: .leading, spacing: 6) {
            HStack(spacing: 8) {
                GeometryReader { proxy in
                    ZStack(alignment: .leading) {
                        Capsule().fill(MacHomeStyle.track)
                        Capsule().fill(MacHomeStyle.emphasisMark)
                            .frame(width: max(MacHomeStyle.meterHeight, proxy.size.width * context.percent / 100))
                    }
```
